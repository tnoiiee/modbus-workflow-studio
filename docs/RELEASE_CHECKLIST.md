# Release Checklist

- [ ] Final scope approved.
- [ ] Correct base tag/commit verified.
- [ ] Target version is new.
- [ ] Versions synchronized.
- [ ] Protected areas reviewed.
- [ ] `npm run check` passed locally or in approved CI.
- [ ] No secrets included.
- [ ] No `node_modules`, `dist`, coverage, runtime data, or generated project data included.
- [ ] ZIP integrity verified.
- [ ] ZIP SHA-256 recorded.
- [ ] Changelog updated.
- [ ] Current state updated.
- [ ] Tag and GitHub Release created.
