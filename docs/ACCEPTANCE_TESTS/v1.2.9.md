# Acceptance Test v1.2.9

Status: approved and implemented scope.

## UI scope

- Google Sans is bundled and used across the application without a runtime network dependency.
- Explicit UI font sizes are increased by 2 px.
- Supporting containers accommodate the larger typography.
- React Flow Controls and MiniMap use visible dark-theme colors, focus, and hover states.
- Logic symbols are centered at the top and enlarged without blocking drag, delete, or handles.
- Block Parameter descriptions show English first and Thai on a separate line below.

## Protected behavior

- No Backend, API, runtime, polling, WebSocket, Modbus, auto-save, revision, engine, dynamic-port, Undo/Redo, or monitor behavior changes.
- React Flow node/edge architecture remains unchanged.
- Modbus Monitor remains read-only.

## Validation

- Root, client, server, UI, health API, startup banner, README, changelog, current state, and lockfile workspace versions are 1.2.9.
- `npm run check` must pass locally or in approved CI before tagging.

## Visual acceptance checks

- Verify English, numbers, and Thai glyphs at 90%, 100%, 110%, and 125% browser zoom.
- Verify 1920x1080, 1600x900, 1366x768, and 1280x720 viewports.
- Verify long workflow, device, node, sub-input, tag, and unit names do not overlap handles or delete controls.
- Verify Controls icons remain identifiable in default, hover, focus, active, and disabled states.
- Verify MiniMap nodes, viewport mask, border, and background remain visible in the dark theme.
- Verify every Logic block symbol is centered and larger while the node remains draggable.
- Verify each Block Parameter description renders English first and Thai on the next line.

## Functional regression checks

- Add, drag, select, connect, disconnect, and delete blocks and edges.
- Exercise Undo/Redo, Fit View, pan, zoom, MiniMap navigation, workflow switching, duplicate, and delete.
- Increase/decrease dynamic Logic inputs and Multi Input outputs without handle or edge regression.
- Verify Reliable Auto-save reaches Saved and does not cross workflow boundaries.
- Run concurrent workflows and verify independent runtime state.
- Verify FC01-FC04 reads and FC05/FC06/FC16 writes against the approved safety policies.
- Verify Modbus Monitor Add Item, Add Range, Read Now, Start/Stop Monitoring, and CSV export remain unchanged.
