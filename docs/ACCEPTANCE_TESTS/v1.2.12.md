## Approved defaults

- Visual direction: restrained dark-first Industrial Cyberpunk
- Responsive target: desktop and tablet landscape, about 1024 px and above
- Accessibility target: WCAG AA contrast, keyboard focus, reduced motion
- Workflow layout: segmented top command bar with **visible Undo, Redo, and Fit View controls**
- Duplicate Block: new ID, copied type/parameters, unique `Copy` name, offset position, no copied edges
- Project Settings: UI-only redesign, no settings API, no persistence, no false success state
- Traffic Monitor: no clear action exists in the baseline and none is approved for v1.2.12
- Block Library search/filter: optional enhancement, non-blocking, not a release gate
- Version: bump to `1.2.12` in the first implementation commit and keep every surface synchronized
- v1.3.0 Published Variables are **deferred, not cancelled**

## Classification legend (owner decision G)

Every row carries exactly one classification:

| Code | Meaning |
| --- | --- |
| `M-MERGE` | Mandatory for merge — the implementation PR must not merge without a recorded PASS |
| `M-REL` | Mandatory for release — required before any tag or release ZIP, may follow merge |
| `COND` | Conditional — mandatory only when the approved environment/fixture is available; otherwise stays `NOT RUN` |
| `NB` | Non-blocking evidence — recorded for review, never gates merge or release |

A `COND` row without an available environment must remain `NOT RUN`. Hardware and extended-soak rows
must never be converted to `PASS` by inference, adjacency, or unit-test success.

## Evidence rule

Each row must record commit SHA, command/fixture/environment, sanitized configuration, timestamps
and duration where applicable, expected and actual result, `PASS` / `FAIL` / `NOT RUN`, and a
screenshot/log/frame capture where appropriate. A `NOT RUN` row never becomes `PASS` because an
adjacent unit test passed.

## Explicit non-claims

Passing the UI screenshot matrix does not prove runtime or write safety. Passing unit tests does not
prove hardware or slow-consumer behavior. Hardware and extended-soak rows remain `NOT RUN` unless the
approved environment and evidence exist. Passing E11 does not imply Project Settings persists anything.
