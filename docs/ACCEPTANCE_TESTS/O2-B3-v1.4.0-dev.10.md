## Implemented architecture and boundaries

[Approved implementation scope, limits and semantics](../SCOPE_O2-B3_v1.4.0-dev.10.md).

Stable Overview-specific external store + adapter; one active B2 headless client per ready active
Overview View. Eligible identities are visible, complete, BOUND, MONITOR, type-compatible SHARED_TAG,
deduplicated/sorted with the existing B2 canonical function. Context carries a stable store reference;
Runtime children use keyed useSyncExternalStore subscriptions. Values never enter Flow node data,
Page/Draft/history/revision/geometry/viewport/Definition/Preview Control state.

Initial Snapshot is published from B2's already-validated public cache at its existing IO socket
factory boundary, before subscription confirmation. The IO delegates to the existing browser adapter;
there is no second REST/WS mechanism or polling path. B2 applies/ACKs independently of presentation.

Edit, inactive Overview, confirmed Page navigation, empty selection and disposal stop/fence the old
client. Page-loading request generations also reject stale configuration loads. Save success and
Cancel start a fresh View Snapshot from saved state; failure stays in Edit. StrictMode-style queued
starts are generation-checked. Hidden/offline browser delivery is paused/disposed, not buffered behind
an animation-frame queue. Returning online/visible uses a fresh Snapshot.

Monitoring matrix:
- NUMERIC_LABEL: finite Number, Definition unit, up to six decimals / scientific fallback.
- STATUS_LIGHT: Boolean TRUE/FALSE, no switch semantics or process interaction.
- VALUE_BADGE: Number or Boolean; no coercion.
- TEXT_LABEL / String-bound Badge: explicit unsupported producer, not missing Definition or fake text.
- Others: no Runtime. SWITCH/PUSH remain independent Preview-only controls with visible warnings;
  navigation remains navigation-only. App/Canvas/persisted model/resolver matrix are unchanged.

Binding, availability, sample quality and browser transport remain separate. Zero/false are valid;
no sample is em dash. STALE/BAD/Device DISCONNECTED/unavailable differ; last-good retains its timestamp
and explicit historical labeling, including an inline label before the value for compact tiles.
Cached data is not fresh GOOD. Connected means channel connected, never caught-up/all-GOOD/exactly-once.
Clock skew is explicit; paused clocks show absolute receive time rather than a frozen elapsed age.
Caption is configuration text, not process data. Full precision/unit/reason/timestamps are in keyboard
accessible details via the existing Modal, outside Flow transforms. No per-sample aria-live.

## Resource and recovery contract

- ≤200 eligible Runtime-bound Elements / ≤200 unique identities per Page; oversize disables the whole
  Runtime selection with an error, not a silent subset. Page/Edit configuration remains usable.
- ≤512 KiB serialized presentation cache /200 items; B2 canonical cache/apply/frame bounds unchanged.
- ≤5 Hz publication after initial Snapshot; ≤1 Hz age. Safety invalidation and transport-state notices
  are immediate and do not fabricate or publish new process samples. One presentation timer and one
  age interval, not one timer per Element. Up to 256 subscribers per item/status/clock observer class.
- B2 alone schedules recovery. Five automatic attempts / rolling 60s. Exhaustion cancels automatic
  work and latches Error. Manual Retry ≤1/sec, never clears recent automatic attempts. Old attempt
  timestamps expire at 60s, but a latched error does not automatically restart. Continuous Connected
  ≥60s allows reset; brief subscribed/Connected does not. Re-entry preserves the window.
- Hidden/offline closes the B2 client and cancels timers; cache is historical only, with absolute time
  while age is paused. Return starts a new Snapshot. Page changes clear old data entirely.
- No whole-process RSS/latency guarantee, Historian/history, replay-complete signal or exactly-once.
