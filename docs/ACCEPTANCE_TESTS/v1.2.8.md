# v1.2.8 Regression Baseline

This document summarizes behavior that later versions must preserve.

- Workflow editor remains visible and interactive.
- Dynamic ports connect without browser refresh.
- Workflow CRUD, selector, save, and revision handling work.
- Multiple workflows can own isolated runtime sessions.
- Shared Modbus device connection and queues remain project-level.
- FC01-FC04 reads and FC05/FC06/FC16 writes remain supported.
- Independent Modbus Multi Input supports 1 to 8 sub-inputs sharing Device and Unit ID.
- Each Multi Input sub-input has independent FC, address, data type, order, scale, offset, unit, scan interval, runtime quality, value, and source port.
- Boolean lamps and logic symbols remain visible without blocking handles.
- Manual Trigger, Audit Viewer, Linear Mapping, and Reliable Auto-save remain functional.
- Modbus Monitor remains read-only and supports lists, Add Item, Add Range, manual read, continuous monitoring, and CSV export.
- CSV export uses CRLF and UTF-8 BOM.
- Disconnect does not generate stale writes.
