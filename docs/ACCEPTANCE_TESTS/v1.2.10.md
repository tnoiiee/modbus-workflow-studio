# Acceptance Test v1.2.10

Status: approved hotfix scope.

## Font loading

- Google Sans static files declare exact weights 400, 500, 600, and 700.
- Italic declares style italic at weight 400.
- Application, form controls, tables, and React Flow explicitly use Google Sans.
- Scoped `!important` is used only for `font-family` within application selectors.
- No global universal font override is used.
- Font files load locally without an Internet dependency.

## Browser verification

- DevTools Styles shows the application Google Sans declaration as the winning rule.
- Computed font family starts with Google Sans.
- Rendered Fonts shows Google Sans.
- Font requests return 200 or 304 with no 404, CORS, MIME, or OTS parsing errors.
- `document.fonts.check` returns true for 400, 500, 600, 700, and italic 400.

## Regression

- v1.2.9 font sizing, container sizing, Controls, MiniMap, logic symbols, and bilingual descriptions remain unchanged.
- Backend, runtime, Modbus, WebSocket, monitoring, auto-save, and React Flow architecture remain unchanged.
- `npm run check` must pass locally or in approved CI before tagging.
