## Scope and acceptance boundaries

- Draft binding contains tagId, tagName, dataType, direction and status. Status is derived from trimmed Tag ID: NOT_BOUND or DRAFT, never CONNECTED. Clearing Tag ID unbinds; name/type metadata may remain. Unknown data type remains valid draft metadata. Direction retains category-specific choices.
- Binding configuration participates in existing Edit Save/Cancel and Undo/Redo. No runtime lookup, external Tag existence check, live value or command dispatch occurs.
- Invalid configuration produces an accessible error, preserves Draft and prevents Page PUT. The Server validation/API contract is unchanged; this is client editor validation, not a new server security boundary.
- Library uses native keyboard-operable disclosure buttons and lists. Inspector help/errors are associated with fields. Escape cancels uncommitted input; panel collapse/expand retains keyboard focus. Existing shared modal trapping, Escape, return-focus and alert behavior remain intact.
- Compact layout must not cover the Canvas with the Inspector. Command Bar and dialogs must remain reachable in short viewports. Responsive styling must not alter Element geometry or savedViewport.
